### Why researchers open Hawkeye

| | |
| --- | --- |
| **Anti-cheat angle** | Live kernel & process inspection — `!probe`, `!etw`, memory — not a slide deck |
| **Lab edition** | Automated high-risk detection + `!analyze` reports on the same bench |
| **Community** | Open source (GPL) — [source & releases](https://github.com/hawkeye-Leo/hawkeye-community) |

**Not a bypass kit.** Authorized research only.

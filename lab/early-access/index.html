Why Lab is $35 / month

Community is the live research console; Lab runs detections aimed at newer stealth techniques — cross-process read/write, physical memory reads, capture-hidden windows, ukexec, and more — on a running system, not by dissecting an offline dump.

!analyze rolls 20+ dimensions into one workflow and produces a scored PDF or text report you can hand off directly.

The behavior-signature library is maintained with your subscription — detection logic and Assessment copy are ongoing research, not a one-off script.

Driver-based on the host OS — detections are built for live Windows research at kernel privilege, without hardware-virtualization (VT-x/AMD-V) or a VM layer for introspection.

Runs on Windows 10/11 x64 with administrator access; no VM setup required.
